# 🍔 Just Do Eat (Test Project)

> **Note:** This repository is an experimental test project built for ISTA Ifrane students.

A Progressive Web App (PWA) designed for food ordering and tracking with real-time updates.

## 🚀 Live Demos
* **Client App:** [https://yanashehe.github.io/just-do-eattest1/](https://yanashehe.github.io/just-do-eattest1/)
---
## ✨ Features
* **Responsive Design:** Optimized for mobile phones and desktop layouts.
* **Interactive Ordering:** Browse items, add custom extras, and manage a live shopping cart.
* **Real-time Tracking:** Syncs orders dynamically using Appwrite Cloud.
* **Data Export:** Built-in tool to export order data to Excel (`.xlsx`).
---
## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Backend & Database:** Appwrite Cloud
* **Hosting:** GitHub Pages
