# 🍔 Just Do Eat

A Progressive Web App (PWA) designed for ISTA Ifrane students to easily browse, order, and track food items with real-time updates and a secure administrative dashboard.

## 🚀 Live Demos
* **Client App:** [https://yanashehe.github.io/just-do-eattest1/](https://yanashehe.github.io/just-do-eattest1/)
---
## ✨ Features

### 🛒 Client Side (`index.html`)
* **Responsive Design:** Optimized for mobile phones and PC/Desktop layouts (grid/sidebar).
* **Interactive Menu:** Browse categories, customize items with extras, and manage a live shopping cart.
* **Order Tracking:** Generates a unique pickup code and slot for every customer order.
---

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, Modern JavaScript (Vanilla)
* **Backend & Database:** Appwrite Cloud (`Project ID: 6ad3bbf5...`)
* **Data Export:** SheetJS (`xlsx`)
* **Hosting:** GitHub Pages
